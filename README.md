# algi_lin_comp

Estudo dirigido de Algebra Linear Computacional sobre o metodo dos Gradientes
Conjugados.

## Como rodar

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gradientes_conjugados.py
.venv/bin/python gerar_graficos.py
```

Os resultados ja calculados estao em `ESTUDO_DIRIGIDO.md`.
